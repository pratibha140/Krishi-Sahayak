Emergency Protocol

{{ t.first_aid_heading }}

{% if language == 'hi' %} छिड़काव के दौरान यदि किसी किसान या मजदूर को चक्कर, उल्टी या बेचैनी हो तो तुरंत ये 4 प्राथमिक कदम उठाएं: {% elif language == 'mr' %} फवारणी करताना चक्कर, उलट्या किंवा अस्वस्थ वाटल्यास तातडीने खालील ४ प्रथमोपचार करा: {% else %} Immediate life-saving emergency actions in case of accidental pesticide contamination or poisoning: {% endif %}

01

{% if language == 'hi' %}सुरक्षित स्थान पर जाएं और सहायता लें{% elif language == 'mr' %}सुरक्षित ठिकाणी जा आणि मदत घ्या{% else %}Move to Safety & Get Help{% endif %}

{% if language == 'hi' %}कीटनाशक वाले क्षेत्र से तुरंत हटें और ताजी हवा में जाएं यदि धुआं या वाष्प सांस में गई हो। कीटनाशक के अधिक संपर्क से बचें। यदि व्यक्ति बेहोश है, सांस लेने में कठिनाई है, दौरे पड़ रहे हैं या गंभीर लक्षण हैं, तो तुरंत आपातकालीन चिकित्सा सहायता लें।{% elif language == 'mr' %}कीटकनाशक फवारणी क्षेत्रापासून दूर मोकळ्या व ताज्या हवेत जा. कीटकनाशकाशी अधिक संपर्क टाळा. व्यक्ती बेशुद्ध असल्यास, श्वास घेण्यास त्रास होत असल्यास, झटके येत असल्यास किंवा गंभीर लक्षणे दिसल्यास त्वरित आपत्कालीन वैद्यकीय मदत मिळवा.{% else %}Move away from the pesticide exposure area and get to fresh air if fumes were inhaled. Avoid further contact with the pesticide. If the person is unconscious, having difficulty breathing, having seizures, or showing severe symptoms, seek emergency medical help immediately.{% endif %}

02

{% if language == 'hi' %}त्वचा के संपर्क में आने पर{% elif language == 'mr' %}त्वचेवर पडल्यास{% else %}Skin Contact{% endif %}

{% if language == 'hi' %}दूषित कपड़े तुरंत उतारें। प्रभावित त्वचा को बहते साफ पानी और साबुन से अच्छी तरह धोएं। कीटनाशक को शरीर के अन्य हिस्सों में फैलने न दें। दूषित कपड़ों को धोने के लिए अलग रखें।{% elif language == 'mr' %}दूषित कपडे ताबडतोब काढा. उघडी पडलेली त्वचा भरपूर स्वच्छ वाहत्या पाण्याने आणि साबणाने स्वच्छ धुवा. कीटकनाशक शरीराच्या इतर भागांवर पसरू देऊ नका. दूषित कपडे धुण्यासाठी वेगळे ठेवा.{% else %}Remove contaminated clothing immediately. Wash exposed skin thoroughly with plenty of clean running water and soap. Avoid spreading the pesticide to other areas of the body. Keep contaminated clothing separate for washing.{% endif %}

03

{% if language == 'hi' %}सांस के द्वारा संपर्क{% elif language == 'mr' %}श्वासावाटे संपर्क{% else %}Inhalation{% endif %}

{% if language == 'hi' %}प्रभावित व्यक्ति को खुद को खतरे में डाले बिना तुरंत ताजी हवा में ले जाएं। व्यक्ति को आरामदायक स्थिति में रखें और उनकी सांस पर नजर रखें। यदि सांस लेने में कठिनाई हो या लक्षण गंभीर हों, तो तुरंत आपातकालीन चिकित्सा सहायता लें।{% elif language == 'mr' %}स्वतःला धोक्यात न घालता बाधित व्यक्तीला तात्काळ ताज्या हवेत न्या. व्यक्तीला आरामदायक ठेवा आणि त्यांच्या श्वासावर लक्ष ठेवा. श्वास घेण्यास त्रास होत असल्यास किंवा लक्षणे गंभीर असल्यास त्वरित आपत्कालीन वैद्यकीय मदत घ्या.{% else %}Move the affected person to fresh air immediately without putting yourself at risk. Keep the person comfortable and monitor their breathing. If breathing is difficult or symptoms are severe, seek emergency medical help immediately.{% endif %}

04

{% if language == 'hi' %}निगलने पर{% elif language == 'mr' %}विषारी पदार्थ गिळल्यास{% else %}If Swallowed{% endif %}

{% if language == 'hi' %}जब तक डॉक्टर, विष-नियंत्रण केंद्र या उत्पाद लेबल पर विशेष निर्देश न दिया गया हो, उल्टी न कराएं। यदि व्यक्ति होश में है और सक्षम है तो मुंह साफ पानी से कुल्ला कराएं। तुरंत चिकित्सकीय सलाह लें।{% elif language == 'mr' %}डॉक्टर, विष नियंत्रण केंद्र किंवा उत्पादनाच्या लेबलवर स्पष्ट सूचना असल्याशिवाय उलटी करवून घेऊ नका. रुग्ण शुद्धीत असल्यास आणि करू शकत असल्यास तोंड पाण्याने स्वच्छ धुवा. त्वरित वैद्यकीय सल्ला घ्या.{% else %}Do not induce vomiting unless specifically instructed by a medical professional, poison-control service, or the pesticide product label. Rinse the mouth if the person is conscious and able to do so. Seek medical advice immediately.{% endif %}

{% if language == 'hi' %}कीटनाशक का डिब्बा या लेबल साथ ले जाएं{% elif language == 'mr' %}कीटकनाशकाचा डबा किंवा लेबल सोबत घ्या{% else %}Take the Pesticide Container or Label{% endif %}

{% if language == 'hi' %} सुरक्षित होने पर कीटनाशक का मूल डिब्बा, उत्पाद लेबल या लेबल की स्पष्ट तस्वीर डॉक्टर या आपातकालीन सेवा के पास ले जाएं। उत्पाद जानकारी से स्वास्थ्य कर्मियों को कीटनाशक की पहचान करने और उचित उपचार तय करने में मदद मिलती है। {% elif language == 'mr' %} सुरक्षित असल्यास कीटकनाशकाचा मूळ डबा, उत्पादनाचे लेबल किंवा लेबलचा स्पष्ट फोटो डॉक्टर किंवा आपत्कालीन सेवेकडे घेऊन जा. उत्पादनाची माहिती आरोग्य कर्मचाऱ्यांना कीटकनाशक ओळखण्यास आणि योग्य उपचार ठरवण्यास मदत करते. {% else %} Take the pesticide container, product label, or a clear photo of the label to the doctor or emergency service when it is safe to do so. Product information can help healthcare professionals identify the pesticide and determine appropriate treatment. {% endif %}
