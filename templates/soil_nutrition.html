Laboratory Standard Method

{{ t.soil_sampling_heading }}

{% if language == 'hi' %} सटीक मिट्टी परीक्षण के लिए सही तरीके से नमूना लेना सबसे महत्वपूर्ण है। नीचे दी गई मानक वैज्ञानिक विधि का पालन करें: {% elif language == 'mr' %} अचूक माती परीक्षणासाठी योग्य पद्धतीने नमुना घेणे सर्वात महत्त्वाचे आहे. खालील प्रमाणित वैज्ञानिक पद्धत वापरा: {% else %} Accuracy of soil analysis is directly related to the quality of the soil sample taken. Follow this standard method: {% endif %}

1

{% if language == 'hi' %}नमूना स्थल चयन{% elif language == 'mr' %}जागा निवडणे{% else %}Select Sampling Spot{% endif %}

{% if language == 'hi' %}खेत में ज़िग-ज़ैग (W-आकार) पैटर्न में 10-15 अलग-अलग स्थानों का चयन करें। मेड़ों व पेड़ों के नीचे से नमूना न लें।{% elif language == 'mr' %}शेतातून नागमोडी (W-आकार) पद्धतीने १०-१५ वेगवेगळ्या जागा निवडा. बांधाजवळून नमुना घेऊ नका.{% else %}Choose 10-15 representative spots across the field in a zig-zag (W-pattern). Avoid spots near bunds, trees, and manure pits.{% endif %}

2

{% if language == 'hi' %}सतह की सफाई{% elif language == 'mr' %}कचरा काढणे{% else %}Remove Surface Litter{% endif %}

{% if language == 'hi' %}ऊपरी घास, पत्तियां व कचरा खुरपी से धीरे से हटा दें। ऊपरी मिट्टी को न खुरचें।{% elif language == 'mr' %}जमिनीवरील पालापाचोळा, गवत हलक्या हाताने बाजूला करा. वरची माती खरवडू नका.{% else %}Gently scrape away surface weeds, dead leaves, and litter without removing the rich topsoil.{% endif %}

3

{% if language == 'hi' %}15 सेमी 'V' कट{% elif language == 'mr' %}१५ सेमी 'V' आकाराचा खड्डा{% else %}Make 'V' Shaped Cut (15 cm){% endif %}

{% if language == 'hi' %}फावड़े या खुरपी से 15 सेमी (6 इंच) गहरा 'V' आकार का गड्ढा बनाएं।{% elif language == 'mr' %}खुरप्याने किंवा फावड्याने १५ सेमी (६ इंच) खोल इंग्रजी 'V' आकाराचा खड्डा खणा.{% else %}Dig a 'V' shaped pit to a depth of 15 cm (plough layer depth for field crops).{% endif %}

4

{% if language == 'hi' %}1 इंच मोटी मिट्टी स्लाइस{% elif language == 'mr' %}१ इंच जाडीचा थर गोळा करणे{% else %}Collect Uniform 1-inch Slice{% endif %}

{% if language == 'hi' %}'V' गड्ढे की दीवार से ऊपर से नीचे तक 1 इंच मोटी मिट्टी की स्लाइस काटकर साफ बाल्टी में डालें।{% elif language == 'mr' %}'V' आकाराच्या खड्ड्याच्या बाजूने वरपासून खालपर्यंत १ इंच जाडीची मातीची चकती काढून बादलीत टाका.{% else %}Cut a uniform 1-inch thick slice of soil from top to bottom of exposed 'V' face into a clean plastic bucket.{% endif %}

5

{% if language == 'hi' %}मिश्रण व चौथाई विधि (Quartering){% elif language == 'mr' %}मिश्रण व १/४ पद्धत (Quartering){% else %}Thorough Mixing & Quartering{% endif %}

{% if language == 'hi' %}सभी नमूनों को मिलाकर 4 बराबर भागों में बांटें। विपरीत भाग हटाएं जब तक 500 ग्राम मिट्टी न बचे।{% elif language == 'mr' %}सर्व माती एकत्र करून ४ समान भागात वाटा. समोरासमोरील २ भाग फेका, ५०० ग्रॅम उरेपर्यंत ही प्रक्रिया करा.{% else %}Mix collected soil thoroughly on a clean sheet, divide into 4 equal quarters until 500g remains.{% endif %}

6

{% if language == 'hi' %}लेबलिंग व KVK लैब जमा{% elif language == 'mr' %}माहिती चिठ्ठी व लॅब तपासणी{% else %}Label & Submit to KVK Lab{% endif %}

{% if language == 'hi' %}साफ थैली में किसान का नाम, खसरा नंबर, फसल लिखकर निकटतम KVK या जिला मृदा प्रयोगशाला में जमा करें।{% elif language == 'mr' %}पिशवीवर शेतकऱ्याचे नाव, गट नंबर लिहून जवळच्या कृषी विज्ञान केंद्रात (KVK) तपासणीसाठी पाठवा.{% else %}Pack in clean cloth bag with label and submit to nearest KVK or District Soil Testing Lab.{% endif %}
